# Slither.io Zoom

Slither.io oyununda fare tekerleğiyle kamera görünümünü değiştirmenizi sağlayan Chrome eklentisi.

## İndir ve kur

1. [Slither.io Zoom 1.0.2 ZIP dosyasını indir](./downloads/Slither.io-Zoom-1.0.2.zip?raw=true) ve bir klasöre çıkar.
2. Chrome'da `chrome://extensions` sayfasını aç.
3. **Geliştirici modu** seçeneğini aç, **Paketlenmemiş öğe yükle** düğmesine tıkla ve `manifest.json` dosyasının bulunduğu klasörü seç.
4. [Slither.io](http://slither.com/io) sekmesini aç veya açıksa yenile.

Daha önce bu eklentiyi elle yüklediysen mevcut eklenti klasöründeki dosyaları ZIP'tekilerle değiştir. Uzantılar sayfasında **Slither.io Zoom → Yeniden yükle** düğmesine bas ve oyun sekmesini yenile.

## Kontroller

| Kontrol | Oyun içindeki etkisi |
| --- | --- |
| Tekerlek yukarı | Uzaklaştırır |
| Tekerlek aşağı | Yakınlaştırır |
| `0` | Normal görünüme döndürür |

1.0.2 sürümünde yakınlaştırma ve uzaklaştırma aralığı iki yönde de 512 kata kadar çıkarıldı. Uzaklaştırdığında ekranda görebileceğin oyun nesneleri sunucunun gönderdiği verilerle sınırlıdır.

[Chrome'un elle eklenti kurulum kılavuzu](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)
